# Pax Napoleonica: narration (Piper TTS)

This folder holds local, free text-to-speech for *Pax Napoleonica: The World That Never Was*.
It uses [Piper](https://github.com/OHF-Voice/piper1-gpl), the maintained successor to `rhasspy/piper`.
Piper runs offline on your machine with no API, account or per-use cost. The engine is GPL-3.0.

## Layout

| Path | What |
|---|---|
| `scripts/episode-01-script.md` | Episode I script as written (with cues) |
| `scripts/episode-01.txt` | Narration-ready version (generated by `prepare_script.py`) |
| `scripts/voice-test-01.txt` | 30-second voice test |
| `prepare_script.py` | Markdown script → narration text |
| `pronunciations.tsv` | Pronunciation fixes, e.g. Württemberg and Baden |
| `check_pronunciation.py` | Shows how a word will be pronounced |
| `narrate.sh` / `narrate.py` | Narration text → WAV |
| `to-mp3.sh` | WAV → podcast MP3 (needs `ffmpeg`) |
| `voices/`, `output/`, `.venv/` | Voice models, generated audio and the Python environment (all git-ignored) |

## One-time setup (Linux / macOS, Python 3.9+)

```sh
cd pax-napoleonica-tts
python3 -m venv .venv
.venv/bin/pip install piper-tts      # ~200 MB inside .venv only
.venv/bin/python -m piper.download_voices en_GB-northern_english_male-medium --data-dir voices   # 63.2 MB
```

## New episode workflow

```sh
python3 prepare_script.py scripts/episode-02-script.md scripts/episode-02.txt
# Review episode-02.txt, then render it:
./narrate.sh scripts/episode-02.txt                  # → output/episode-02_<voice>.wav
./to-mp3.sh output/episode-02_en_GB-northern_english_male-medium.wav
```

`prepare_script.py` speaks the chapter and epilogue headings ("Chapter One. The Emperor's Gambit.").
It drops the title block, `**NARRATOR:**` labels and the prologue heading.
`[MUSIC]` and `[SOUND]` cues are kept as unspoken lines, each followed by a 3-second gap for music.

Pacing: `LENGTH_SCALE=1.2 PARAGRAPH_SILENCE=1.2 ./narrate.sh ...` gives a slower read with more gravitas.
Neither script overwrites existing files. Rename or delete an old take first, or pass an explicit output path as the third argument.

## Pronunciation

```sh
.venv/bin/python check_pronunciation.py Talleyrand Austerlitz
```

If a word sounds wrong, add `word<TAB>phonemes` to `pronunciations.tsv` and re-run `prepare_script.py`.

## Play and export

```sh
ffplay -autoexit output/episode-01_en_GB-northern_english_male-medium.wav   # or aplay / afplay
./to-mp3.sh output/episode-01_en_GB-northern_english_male-medium.wav        # -16 LUFS, 128 kbps mono
```

[Audacity](https://www.audacityteam.org/) is free and can also open the WAV and export it as an MP3.
